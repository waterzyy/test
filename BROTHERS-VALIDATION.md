# Проверка подготовленного комплекта

Всего **423** выполненные автоматические проверки, все прошли:

| Компонент | Проверок | Что это подтверждает |
|---|---:|---|
| Роутер C# | 58 | преобразование осей, частота, UDP round-trip, остановка/отключение |
| Контроллер Lua | 109 | сохранённые сценарии прицела/выхода/блока, роли, таймауты, локальное взаимодействие |
| Сервер контроллера JS | 19 | пакет/порт/ID валидация и адресная пересылка |
| Игровой мир core/server/client | 68 | общий spawn, здоровье, blips, разрешённые товары, safe-position branch, E/DS4, лимит машин |
| Админ/ACL | 41 | выдача хосту на real ID, transfer/drop/restart/reuse, refresh vMenu |
| Экспериментальные активности | 44 | раунды, права, последовательность, счёт, геометрия, очистка, source guards |
| Установщик PowerShell | 42 | официальный URL, archive traversal/links, ключ без исполнения cfg, pin/hash, loopback busy/free TCP+UDP, синтаксис |
| Состав/конфигурация | 42 | приватный bind, лимит2, порядок/resources, совпадение копий, manifest assets, хеши/PE, отсутствие ключей |

Команда для разработчика: bash run_checks.sh с .NET8 SDK, Node, Lua5.3+, PowerShell и Python3. Пакетный Windows EXE selftest: 01-controller\CoopInputRouter.exe --selftest. Контроль исходных файлов на ПК: VERIFY-CONTENT.cmd после распаковки доверенного ZIP.

Логи сохранены в TEST_RESULTS.txt и tests. Возвраты ошибок тестов сохраняются, нулевая ошибка не маскируется выводом в файл.

**Не проверено:** реальное выполнение Windows EXE, чтение именно пользовательского DS4, официальный resolver/runtime FXServer (cloud proxy403), действительность пользовательского ключа, запуск FXServer/vMenu, GTA-геометрия и реальные игровые анимации. Полноценный игровой прогон должен пройти на ПК пользователя по README_RU.md. Подтверждение пользователем рабочей v1.3 относится к исходному контроллеру, а не к ещё не запущенным серверным ресурсам.

Файлы vMenu/7-Zip/базовых ресурсов взяты с официальных источников; это не результат антивирусной экспертизы. Прочтены их лицензии/зависимости и относящиеся к интеграции части исходников, весь код движка FXServer и сторонних проектов не проходил полный независимый аудит.
