# Вечер для двоих

Автономная HTML-панель с идеями для двух игроков FiveM.

Сборка и проверка логики: `python3 build.py`, затем `node test-core.cjs`. Нужны Python 3 и Node.js; внешние зависимости не требуются. HTML содержит собственный интерфейс и логику.

52 проверки логики и 14 сценариев в Chromium пройдены. Браузерная проверка: локальный HTTP, перезагрузка/таймер/запрет хранилища/повреждённые данные/имена как текст/фильтры/журнал/смена ролей/отмена/ширина390px. Внешних запросов и ошибок JavaScript нет. Запуск file:// в Windows и выполнение заданий в игре здесь не проверялись.
