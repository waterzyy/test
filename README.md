# coop-split 1.2 — бег, цифровые педали и драка

Обновление ресурса для двух локальных клиентов FiveM и DS4. Исправления 1.2 находятся в coop_input/client.lua; роутер 1.1 совместим и не изменён. Готовый EXE включён в полный комплект. Доступен также небольшой архив только ресурса, без необходимости скачивать EXE повторно.

## Обновление установленной версии 1.1

1. Сохраните копию старой папки ресурса coop_input.
2. Распакуйте coop-input-update-v1.2.zip. Замените папку coop_input в resources вашего локального FXServer папкой из обновления. Не оставляйте одновременно два запущенных экземпляра этого ресурса.
3. В консоли FXServer выполните restart coop_input. Новый HUD второго клиента должен содержать P2 v1.2. Это подтверждает загрузку обновлённого клиента.
4. Старый исправленный роутер 1.1 можно оставить запущенным. Отпустите все стики, курки и кнопки для повторного включения ввода (200 мс нейтрали).
5. Если раньше камера работала только в manual, снова выполните coop_camera manual в F8 второго клиента после перезапуска. Настройки команд действуют до следующего перезапуска; постоянные значения находятся в CFG в начале client.lua.

## Новый бег

Пешком наклоните левый стик и удерживайте крестик. Режим repeat создаёт последовательность нажатий SPRINT на стороне клиента каждый кадр, имитируя повторное нажатие кнопки. При запросе спринта движение нормализуется до полной силы в выбранном направлении: частичный наклон не оставляет персонажа на медленном шаге. После отпускания крестика или стика повтор останавливается.

Во время прицеливания, выбора оружия и драки спринт не подаётся одновременно с другими действиями. В боевой стойке крестик означает тяжёлый удар — как в таблице контролов GTA. После выхода из стойки он снова отвечает за бег.

Обычная выносливость GTA сохранена. Если хотите для локальной игры спринт без истощения, во втором клиенте F8: coop_stamina on. Выключить: coop_stamina off. Подпитка выносливости выполняется только при запросе спринта. Для серверов со своей системой голода/выносливости такой настройки может быть недостаточно.

Альтернативный режим для настройки игры с нативным удержанием: coop_sprint hold. Вернуть основной: coop_sprint repeat. Это не изменение скорости персонажа и не принудительная задача бега; ограничения самого движка и серверных ресурсов остаются в силе.

## Машина: газ и тормоз 0/100%

По умолчанию включён DIGITAL:

- R2 выше небольшого порога включения = 100% газа, независимо от дальнейшей силы нажатия.
- L2 выше порога = 100% тормоза; задний ход обрабатывает штатная GTA после остановки.
- При одновременно нажатых L2 и R2 приоритет у тормоза, газ = 0. Отпустите L2, чтобы ехать вперёд.
- Отпущенный курок = 0. Разные пороги включения/отпускания подавляют дребезг около центра.
- Крестик = ручник. При удержании крестика машина заторможена: для движения отпустите его.
- Левый стик = линейный руль; полный выворот достигается при 85% обработанного диапазона отправителя. По центру руль сразу обнуляется, дополнительного сглаживания руля нет.
- R3 = смотреть назад, L3 = сигнал, треугольник = выйти, вправо = фары, влево = радио.
- L1+R1 = огонь из машины. R2 не стреляет одновременно с газом; R1 не включает ручник.
- Пассажиру не подаются газ, тормоз и руль. Для L1+R1 у пассажира используются отдельные INPUT_VEH_PASSENGER_AIM/ATTACK (91/92).

Курки должны пройти уже существующую аппаратную мёртвую зону роутера и порог 0.05 нормализованного пакета; отпускание около 0.02. Это небольшой порог против шума, а не регулировка мощности. Альтернативный аналоговый режим: coop_pedals analog. Вернуть 0/100%: coop_pedals digital.

HUD показывает фактические значения, переданные скриптом в натив управления: DIGITAL GAS 1 BRAKE 0, STEER и число возвратов false от SetControlNormal (rejected). Если GAS 1, BRAKE 0, ручник отпущен, но автомобиль стоит, нужно проверять двигатель, состояние машины, другой ресурс, блокирующий controls, и фокус. HUD подтверждает попытку подачи ввода, а не реакцию игрового движка. Скрипт намеренно не чинит повреждённые машины, не запускает двигатель принудительно и не снимает блокировки других ресурсов.

## Драка

Для боя без огнестрельного оружия удерживайте L2, чтобы перейти в боевую стойку:

- Круг — лёгкий удар (140).
- Крестик — тяжёлый удар (141), одновременно бег не подаётся.
- R2 — альтернативный удар (142), обычный ATTACK не дублируется.
- Квадрат — блок/уклонение средствами движка (143), одновременно прыжок не подаётся.

Удерживаемые ударные кнопки создают новые нажатия, чтобы не оставлять одну зажатую атаку. При блоке удары подавляются; для удара отпустите квадрат. С открытым колесом оружия атаки и спринт отключены.

Холодное оружие определяется через GROUP_MELEE. С огнестрельным оружием вне боевой стойки круг — перезарядка, R2 — выстрел, L2 — прицел. Вне боевой стойки квадрат — прыжок, крестик с движением — бег. Удачно ли прошёл удар или уклонение, определяет GTA: дистанция, анимация, состояние цели и серверные правила.

## Первая установка полного комплекта

1. Распакуйте весь архив в отдельную папку, не запускайте EXE внутри ZIP. Сохраните резервные копии прежнего ресурса и EXE.
2. Скопируйте coop_input в resources локального FXServer. В server.cfg:

       set coop_input_port 30126
       ensure coop_input

3. Запустите FXServer и подключите оба FiveM. В консоли сервера: coopstatus; при необходимости setp2 ID_ВТОРОГО_ИГРОКА. Это серверный ID, не номер окна Windows. setp2 auto — автовыбор; setp2 0 — отключить маршрутизацию.
4. Подключите DS4 по USB, закройте x360ce и старые копии роутера. Запустите start-ds4-router.cmd рядом с новым EXE. Порт роутера и ресурса должен совпадать; 30126 не должен совпадать с игровым портом FXServer.
5. Отпустите всё управление до OK. Нормальная частота около 60 pkt/s. Роутер уже переводит DirectInput в нормализованный формат, поэтому оставьте coop_profile xinput.
6. Используйте оконный/безрамочный режим. Если доступен Pause On Focus Loss — выключите его для фонового клиента. Если камера в фоне не реагирует, F8 второго клиента: coop_camera manual. Вернуть: coop_camera native. Режимы не применяются одновременно.

Не требуются права администратора и открытие UDP-порта в интернете. Приёмник слушает только 127.0.0.1; сервер и роутер должны быть на одном ПК. Роутер не скрывает физический DS4 от первого окна; разделение видимости через HidHide/эмуляторы, если требуется, настраивается отдельно.

## Диагностика

- После обновления HUD должен писать P2 v1.2. Если версия старая — проверьте папку ресурса и restart coop_input.
- STALE/0 pkt/s: проверьте роутер, USB, coopstatus, порт и назначение P2.
- NOT ARMED: отпустите все кнопки/стики/курки, проверьте состояние покоя через diagnose-ds4.cmd.
- Педали: DIGITAL GAS 1 BRAKE 0 — полный газ. BRAKE 1 — отпустите L2. Крестик в машине — ручник.
- Бег: SPRINT в repeat чередует 0/1; это предусмотренные повторные нажатия. В стойке MELEE крестик — удар, не бег.
- Если данные в HUD правильные, а игра их игнорирует, нужны вывод coopstatus, HUD, поведение в активном/фоновом окне и сведения о ресурсах управления/камеры/машин.
- coop_calibrate — отключить до общей нейтрали; coop_debug — HUD; coop_invert — Y камеры; coop_resetcam — за спину.
- В diagnose-ds4.cmd видны фактические диапазоны осей, RAW и нормализованный JSON. По умолчанию LX=X, LY=Y, RX=Z, RY=RotationZ, LT=RotationX, RT=RotationY. Другую подтверждённую карту задаёт параметр --axes; не выбирайте её наугад.

## Проверки и пределы проверки

Для версии 1.2:

- 66 проверок клиента с имитацией API FiveM: цифровые педали, отпускание/дребезг, приоритет тормоза, руль, пассажирские контролы, контекст и повторы драки, бег при 30/60/144 FPS, пауза/смерть/таймаут, роли, камера и валидация пакетов.
- 16 проверок серверной пересылки с имитацией Cfx API и сокета, плюс node --check.
- 55 проверок роутера: нормализация осей/кнопок, JSON, настоящий локальный UDP round-trip и потеря контроллера. Код роутера и Windows EXE не изменялись относительно 1.1.

Повторить: bash run_tests.sh (.NET 8 SDK, Node.js, Lua 5.3+; здесь используется fengari). При ошибке Lua стенд явно завершает процесс с ненулевым кодом. Сам готовый EXE на Windows: CoopInputRouter.exe --selftest. Пересборка EXE при необходимости: build-win-x64.cmd.

Физический DS4, Windows DirectInput и два настоящих окна FiveM здесь не запускались. Подача правильного ввода в имитации не доказывает поведение движка на конкретном ПК. Раскладка рассчитана на ходьбу, бой и обычные дорожные машины; самолёты, вертолёты, специальные машины, меню и телефон полностью не реализованы. Версия исправляет перечисленные ошибки; отсутствие всех возможных багов не гарантируется.
