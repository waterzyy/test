# Исправление ванильной сессии 1.1

В [архиве переноса 1.1](https://raw.githubusercontent.com/waterzyy/test/downloads/brothers-vanilla-import-v1.1.zip) заменены персонажи player_zero/player_one на a_m_y_business_02/a_m_y_hipster_01; конфиг включает OneSync. Ресурс возвращает обоих игроков в bucket 0 при входе/hello и каждые 3 секунды. После спавна видимость восстанавливается только у собственного ped. Модель не сбрасывается каждый кадр, контроллер 1.4 не менялся.

`brothers_sync` в консоли показывает режим, число игроков, bucket, координаты и последний список реально активных player ped каждого клиента. `brothers_sync fix` доступен консоли/хосту: общий bucket, восстановление собственной видимости и запрос спавна в хабе. Устаревшие/отсутствующие отчёты помечаются явно; оффлайн-режим требует полного перезапуска.

Для уже установленного переноса достаточно заменить ресурс brothers_world и brothers-vanilla.cfg из архива, включить OneSync в txAdmin при его использовании, полностью перезапустить FXServer и оба клиента. Существующие ключ и endpoints не заменяются. Этот профиль рассчитан на двух доверенных игроков на одном ПК, не на RP-инстансы.

83 проверки игровой логики (13 core, 28 server, 27 client, 15 session) и 42 проверки состава/конфигурации пройдены. Для запуска тестов: `lua tests/world/test_session.lua brothers_world/` (Lua 5.3+, аналогично для трёх остальных тестов). Реальная репликация FiveM, пользовательский старый server.cfg и два Windows-клиента здесь не запускались. OneSync off был недостаточно надёжным выбором для такой схемы; принадлежность к разным bucket в конкретной пользовательской сессии без её диагностики не подтверждена.
