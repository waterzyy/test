# brothers_world

Лёгкий ресурс для двух локальных клиентов FiveM. Использует только штатные GTA модели, погоду и игровые native-функции; без базы данных, NUI-браузера, сторонних DLL, карт/MLO и внешних запросов.

## Возможности

- Общая стартовая точка на парковке Legion Square, два близких места без наложения. Первый игрок — `a_m_y_business_02`, второй — `a_m_y_hipster_01`; внешность затем можно менять через vMenu.
- Основной режим: health 300, armour 100; экспериментальный: health 350, armour 100. Это не godmode. NPC, взрывы и аварии остаются опасными. Огонь игроков друг по другу выключен, но это не обещание защиты от всех видов физического урона, например автомобиля.
- Смерть: через 6 секунд респавн в безопасном месте рядом с живым братом. Запрашивается pavement navmesh вне воды/интерьеров, проверяются расстояние и перепад высоты. Для удалённого брата загружается небольшая collision scene. Если безопасное место не найдено, используется известный общий хаб.
- Метка с именем брата остаётся на карте даже вне зоны streaming персонажей: позиция передаётся раз в секунду, координаты проверяются сервером, старые метки удаляются. Это не постоянное сканирование всех объектов мира.
- Обычный GTA город с населением и трафиком: main peds 0.50, traffic 0.50, parked 0.35; experimental 0.40/0.40/0.30. Значения применяются раз в кадр, как требует API. Нет бесконечных ручных спавнеров NPC.
- Бесплатные точки лечения/брони, оружия/патронов, ремонта и выдачи транспорта. Это простой кооперативный sandbox, а не вся экономика/миссии/магазины одиночной GTA.
- Личный транспорт ограничен одной машиной на игрока. Ресурс заменяет только свою предыдущую пустую машину; машину с братом внутри не удаляет. Пустая личная машина убирается после 10 минут без использования. Чужие и vMenu-машины не сканируются и не удаляются.
- В экспериментальном режиме дополнительно доступны штатные DLC Vigilante, Rocket Voltic и Ramp Buggy. Нужен игровой build, в котором эти модели присутствуют (комплект использует 3095).

## Зависимости и порядок запуска

```cfg
set onesync on
set brothers_experimental 0
set brothers_health 300
ensure spawnmanager
ensure brothers_world
ensure coop_input
```

Для второй папки сервера `set brothers_experimental 1`; если не переопределять `brothers_health`, будет 350. `spawnmanager` — официальный стандартный ресурс Cfx.re. Не запускайте после `brothers_world` другой gamemode, который включает собственный случайный автоспавн, и не запускайте два ресурса смерти/респавна одновременно.

Ресурс рассчитан на `sv_maxclients 2` и включённый OneSync (`set onesync on`). За это ограничение также отвечает конфигурация сервера: третий клиент не получает игровой слот ресурса, но ресурс сам его не кикает.

## Управление

- `E` у маркера — получить указанный товар бесплатно. Клавиша привязана через `RegisterKeyMapping` к `brothers_interact` и общему локальному событию, поэтому работает и за рулём у ремонта. Отдельного опроса контрола 46 нет — событие не дублируется.
- У второго геймпада крестовина вниз вызывает локальное `brothers_world:interact`; в контроллерном ресурсе должно быть соответствующее событие. Мировой ресурс делает действие только в радиусе 2.6 м точки. Вне магазина это событие ничего не делает, поэтому экспериментальные задания могут слушать его отдельно.
- `F6` или `/coophelp` — информационная панель без захвата мыши/NUI.
- `/regroup` — переместить только себя к брату/хабу; серверный cooldown 15 секунд.
- `together` в консоли сервера — вернуть обоих в хаб. Игроку разрешается только при ACE `brothers.manage`. Для комплекта: `add_ace group.brothers_host brothers.manage allow`.

Точки хаба лежат примерно между `(201,-824)` и `(235,-799)`. Дополнительные точки: Pillbox `(307,-595)`, Ammu-Nation `(22,-1107)`, магазин `(26,-1347)`. Все отмечены на карте, действие указано у маркера. Место выдачи должно быть свободно; занятая площадка не очищается удалением посторонних машин.

## Время/погода и интеграция

При подключении применяется CLEAR, 15:00. Постоянного сброса времени/погоды нет — vMenu или другой согласованный ресурс может менять их после старта.

Серверный экспорт для других доверенных локальных ресурсов:

```lua
exports.brothers_world:SetEnvironment('RAIN',18) -- whitelist погоды, целый час 0..23
local hub=exports.brothers_world:GetHub()
```

Не запускайте сразу несколько постоянных циклов изменения времени/погоды. Встроенные vMenu player blips в комплекте отключаются, чтобы не дублировать метки этого ресурса.

## Граница доверия

Сервер принимает только ID фиксированной точки, сам выбирает известный model/weapon/item; произвольные координаты, количество и модели в запросе покупки не принимаются. Есть cooldown и проверка регистрации. В main сервер отказывает экспериментальным товарам даже при подделанном ID. Клиент дополнительно проверяет близость к точке и источник server event.

Близость точек снабжения проверяется на клиенте, поэтому ресурс рассчитан на доверенную локальную игру, а не публичную экономику. Не публикуйте такой sandbox без отдельного аудита публичного сервера. В нём нет реальных денег, сохранения инвентаря и секрета лицензии.

## Проверки

Из корня сборки:

```bash
lua tests/world/test_core.lua
lua tests/world/test_server.lua
lua tests/world/test_client.lua
```

Нужен Lua 5.3+ (или fengari). Тесты проверяют исходные файлы и завершаются ненулевым кодом при ошибке.

- 13 pure-проверок: общий спавн, близость точек, режимы, фильтрация безопасного респавна и UTF-8 текста.
- 28 server-проверок: слоты, выдача только разрешённых товаров, cooldown, запрет experimental в main, проверка/частота позиции, ACE и disconnect.
- 27 client-проверок с подставным API: спавн, здоровье, source guard, близость выдачи, дальние метки, безопасная collision/navmesh ветка респавна, ограничение машины/запрет удаления занятой братом и ремонт только за рулём.

Дополнительно 15 session-проверок: общий bucket, восстановление видимости своего ped, настоящие списки активных игроков для отчётов, права команды и отсутствие ложного успеха при OneSync off. Всего 83 проверки. Настоящий Windows FXServer, два клиента FiveM, геометрия Legion Square, задержки navmesh и анимации в этой среде не запускались. Требуется первый игровой прогон на ПК пользователя; тестовый API не доказывает реакцию движка.

## Синхронизация 1.1

Полностью перезапустите сервер и оба клиента после включения OneSync. В консоли `brothers_sync fix`, через 5 секунд `brothers_sync`: ожидаются два игрока, bucket 0 и близкие координаты. Общий bucket поддерживается каждые 3 секунды; RP-инстансы и другие обработчики спавна нужно отключить. Подробная инструкция находится в корне архива переноса.
